⚙️ JARVIS Settings

OpenAI चुनने पर यहाँ अपने deployed Worker का URL डालें। URL में /chat न जोड़ें; JARVIS खुद जोड़ देगा।

सुरक्षा: API Key इस ब्राउज़र के local storage में सेव होगी। वेबसाइट/डिवाइस तक पहुँच रखने वाला व्यक्ति इसे निकाल सकता है। इसे सार्वजनिक या साझा डिवाइस पर सेव न करें।
OpenAI Key वेबसाइट में नहीं डालें। इसे Cloudflare Worker के Secret में OPENAI_API_KEY नाम से रखें। OpenAI API का बिल ChatGPT subscription से अलग होता है।

Gemini ब्राउज़र से चलता है। OpenAI के लिए Cloudflare Worker proxy इस्तेमाल होगा ताकि आपकी OpenAI Key छिपी रहे।
